# LCC 换流器（电网换相换流器）学习笔记 + PSCAD 建模方案

## 一、LCC 是什么
LCC（Line-Commutated Converter，电网换相换流器）= 传统 HVDC 换流器，基于**晶闸管**（半控器件），
依靠交流电网电压实现自然换相。特点：大容量（GW 级）、高效率（~99%）、需吸收无功、可能换相失败。
与 VSC（电压源换流器，全控器件 IGBT，自换相）相对。

## 二、结构（由外到内）

```
交流系统 ──交流滤波器/无功补偿── 换相变压器 ── 6脉动桥 ×2 (12脉动) ── 平波电抗 ── 直流线路/负载
            (12k±1次谐波)      (YY+YD, 30°移相)  (晶闸管阀组)      (Ld)
```

1. **晶闸管阀（Thyristor Valve）**：多个晶闸管串联（耐压）+ 均压电阻 + RC 缓冲（snubber, RD/CD）
   + 触发单元（TE）。半控：导通后靠电流过零关断。
2. **6 脉动桥（Graetz Bridge）**：6 个阀构成三相桥式整流。导通顺序 1-2-3-4-5-6，
   每阀导通 120°（含换相重叠）。上桥臂 1-3-5，下桥臂 2-4-6。
   - 触发角 α：阀正向电压后延迟 α 触发（α 从自然换相点算起）
   - 换相重叠角 μ：两阀同时导通期间（换相电抗导致电流转移需要时间）
   - 熄弧角 γ：阀电流过零后到电压反向的时间（γ = 180° − α − μ）
3. **12 脉动换流器**：2 个 6 脉动桥**直流侧串联**，交流侧经 YY 和 YD 变压器（副边 30° 相位差）
   供电 → 两桥触发相差 30° → 直流纹波 12 脉动（谐波 12k±1 次，最低 11/13 次）
4. **换相变压器**：漏抗即换相电抗 Xc（典型 0.1~0.2pu，CIGRE 用 0.18pu）——决定 μ 和换相压降
5. **平波电抗器 Ld**（CIGRE 0.5968H/极）：平抑直流电流纹波、限制故障电流上升率
6. **交流滤波器+无功补偿**：12 脉动产生 11/13 次等谐波；换流器吸收无功 ≈50~60% 有功功率

## 三、基本方程（经典）

- 理想空载直流电压（6 脉动）：**Vd0 = (3√2/π)·Vll = 1.35·Vll**（Vll 副边线电压有效值）
- 12 脉动：**Vd0 = 2 × 1.35 × Vll**（两桥串联）
- 实际直流电压：**Vd = Vd0·cosα − (3/π)·Xc·Id = Vd0·cosα − Rc·Id**（Rc=3Xc/π 换相压降）
- 换相重叠角：**cos(α+μ) = cosα − 2Xc·Id/(√2·Vll)**
- 熄弧角：**γ = 180° − α − μ**（逆变侧关键量）
- 有功：P = Vd·Id；无功：Q = P·tanφ（整流 cosφ ≈ cosα − RcId/Vd0）

## 四、完整控制逻辑（HVDC 两端标准控制，CIGRE benchmark 结构）

```
                ┌─────────── 整流器（定电流）───────────┐
   Id 测量 → 滤波 → 比较(Iord−Id) → PI → α指令(5°~20°) → 触发脉冲
                └─────────── 逆变器（定熄弧角）──────────┘
   γ 测量 → 比较(γref−γ) → PI → β指令 → α=180°−β(90°~150°) → 触发脉冲
                └─────────── 电流裕度 ───────────┘
   逆变电流指令 = Iord − Imargin(0.1pu)；max/min 选择接管
                └─────────── VDCOL ───────────┘
   直流电压低 → 降低电流指令（防连续换相失败，助恢复）
```

1. **整流器：定电流控制（CC）**——PI 调 α（限幅 α_min~α_max，典型 5°~90°；稳态 12°~20°）
   使 Id 跟踪电流指令 Iord
2. **逆变器：定熄弧角控制（CEA）**——PI 调 β（α 逆变换流角 90°~150°）保持 γ=γref（15°~18°），
   防止换相失败（晶闸管关断时间 ~7°）
3. **电流裕度控制**：正常整流 CC、逆变 CEA；整流故障（电压跌）时电流跌落，
   逆变器因裕度自动转为 CC（电流指令 Iord−Imargin），维持电流传输；
   整流器退到 α_min。实现：maxmin 选择器（逆变取 max(CEA, CC)，整流取 min(CC, α_max)）
4. **VDCOL（低压限流）**：Vd 低于阈值时按曲线降低 Iord（如 0.3pu 电压→0.3pu 电流）
5. **触发脉冲生成**：等间隔触发（锁相 + α 指令 → 每个阀在 α 处触发），
   高级用精确插值（FDT）实现换相点插值

## 五、PSCAD 实现要点（基于 CIGRE_Benchmark.pscx 分析）

**核心组件（master 库自带）：**
- **g6p200_2**（6 脉动桥）：端口 DP/DN（直流±）、Z1/Z2/Z3（交流）、**AO**（触发角指令,度）、
  AM（交流电流测量）、GM（熄弧角测量）、KB/CB、FPN（外部脉冲, FP=1/2）、FDT
  - 参数：UP（脉动数）、**FP**（0=内部触发角跟踪PI+AO输入 / 1,2=外部脉冲 / 3=直接AO）、
    SNUB（RC缓冲 RD=5000Ω/CD=0.05µF）、TfPh（变压器相移补偿, ±30°）、
    FR（频率）、GP/GI（桥内触发角跟踪 PI，CIGRE 用 10/50）、RON/ROFF（阀电阻）、
    Tblock（阻断时间 0.04s）
- **mingam**（最小熄弧角测量）：FREQ 参数，IN/OUT
- **xfmr-3p2w**（换相变压器）：Xl=0.18pu（CIGRE），V1/V2 变比，YD1/YD2 连接组
- 控制器：pi_ctlr + realpole（测量滤波）+ maxmin/compare（裕度选择）

**CIGRE benchmark 参考参数（50Hz/345kV 两端）：**
- 整流变压器：603.73MVA、345/213.456kV、Xl=0.18pu（YY 与 YD 各一）
- 逆变变压器：591.79MVA、230/209.229kV、Xl=0.18pu
- 桥触发：FP=0、GP=10、GI=50、TfPh=±30°、SNUB(RD=5000Ω/CD=0.05µF)、RON=0.01Ω
- 整流定电流 PI：GP=0.7506、TI=0.0544s、输出限幅 0.52~1.57rad（30°~90°）、初值 90°
- 逆变 CEA PI：GP=0.63、TI=0.01524s、输出 0.52~1.92rad、初值 110°
- 直流平波电抗：0.5968H/极
- 电流测量滤波：realpole G=0.5、T=0.0012s；裕度选择 maxmin（Type 0/1）

## 六、建模方案（本任务：单端 12 脉动整流器 + 定电流控制）

**拓扑**（60kV/60Hz，与用户既有模型风格一致）：
```
60kV 交流源 → 换相变压器 YY(60/25kV) → 6脉动桥1 →┐
            → 换相变压器 YD(60/25kV) → 6脉动桥2 →┼ 串联 → Ld → Rl(直流负载)
                                                └→ Vd, Id 测量
控制：Id测量 → realpole滤波 → 与Iord比较 → pi_ctlr → α指令(限幅5°~90°) → AO(两桥)
显示：Vd、Id、α、γ、触发脉冲
```

**参数设计**：
- 交流：60kV、60Hz（源阻抗小，短路比大）
- 变压器：每桥 60MVA 左右，V1=60kV，V2=25kV，Xl=0.18pu（YY 与 YD）
- 直流：Vd0 = 2×1.35×25 = 67.5kV；α=15° → Vd ≈ 65kV；设计 Id=1kA → Rl≈60Ω；Ld=0.2H
- 桥：g6p200_2 ×2（FP=0，TfPh=+30/−30，SNUB，GP/GI=10/50）
- 控制：pi_ctlr（GP=0.75、TI=0.0544s 参考 CIGRE，输出 5°~90°）+ realpole 滤波
- Iord 用 const（0.5~1.2kA 可调）+ VDCOL 简化（可选）

**验证目标**：
1. 稳态：Vd≈Vd0·cosα−Rc·Id（理论校验）、Id 跟踪 Iord、α 稳态 ~15°~20°
2. 动态：Iord 阶跃 → Id 跟踪；α 响应
3. 12 脉动验证：直流电压纹波 12 脉动、交流电流 11/13 次谐波特征

## 七、已验证的 PSCAD 实现细节（2026-08-22，ess_lcc 运行验证通过）

以下内容全部经过"最小复现 + 对照 CIGRE 生成代码"验证，纠正了早期笔记中的错误认知：

### 1. 换相变压器 xfmr-3p2w 的端口语义（View=1 时）
- **N1（px −54,0，dim=3）= 原边三相绕组端口**（接交流源）
- **N2（px +36,0，dim=3）= 副边三相绕组端口**（接 6 脉动桥 N）
- **G1（px −18,36，dim=1）= 原边星点/组端口**——星形接法时**直接接地**（CIGRE 即如此）
- **G2（px 0,36 或 0,0，dim=1）= 副边星点/组端口**——浮动即可（三线制）
- 早期笔记误以为 G1/G2 是三相绕组端口——**错误**；绕组端口是 N1/N2（dim=3），
  G1/G2（dim=1）是星点/中性端口，可与 dim=3 线混连会报 "dimension mismatch 3 != 1"

### 2. g6p200_2 6 脉动桥的端口语义（View=1 时）
- **N（px −36,0，dim=3）= 交流三相功率端口**（接变压器副边 N2，阀支路电源侧）
- **CB（px −18,−90，Integer 输入）= 交流同步基准节点号**！
  桥内锁相/触发同步用 `$CB:N(1..3)` 取该节点三相电压。CIGRE 接法：
  **Rbus（三相母线）→ nodeloop（三相机电节点）→ nodeloop 的 X1（Integer 输出=节点号）→ CB**
- **KB（px 54,54，Integer 输入）= 解锁/闭锁**：**KB=1 运行、KB=0 闭锁**！
  （CIGRE 的 KBR 由比较器在 t>0.04s 后置 1；早期笔记"KB=0 运行"是错的，
  那正是桥不触发的根因）
- **AO（px 54,36，Real 输入）= 触发角指令**：FP=0 时单位是**弧度**（0.52~1.57=30°~90°），
  FP=3 时是度（内部 ×PI_BY180）。早期笔记"FP=0 用度"是错的
- AM/GM（Real 输出）= α/γ 测量（弧度）
- 触发脉冲：FP=0 由桥内等间隔触发（GP/GI=10/50 是触发角跟踪 PI），
  TfPh 补偿变压器相移：**YD 副边馈电桥 TfPh=−30°，YY 馈电桥 TfPh=0°**

### 3. 同步机制（12 脉动正常工作的关键）
- 桥的阀支路功率取自 N 端口（变压器副边电压）
- 但触发同步参考取**原边母线电压**（CIGRE：Rbus；本项目：source3 输出节点）
- 原边/副边相位差由 TfPh 补偿 → 两桥 TfPh=0/−30 对应 YY/YD

### 4. 其他已验证要点
- **source3 必须同时设 Vm 和 Es**（Es 是实际内部电压，默认 230kV，只设 Vm 会以 230kV 输出！）
  Ctrl=0（Fixed）、View=1（N3 为 dim=3 输出）
- 信号扇出：同名 datalabel 自动合并（ESS 同款模式）；INTEGER 信号可经 datalabel 传递
- 换流器直流侧必须有接地参考：CIGRE 把 YY 桥 DN（直流负）直接接地
  （本项目用 1MΩ 中点接地等效，已验证可行）
- 电流测量：ammeter 的 Name 参数即命名信号；realpole 滤波 G 必须=1（kA 直通），
  CIGRE 的 G=0.5 是配合其 pu 标幺，直接照搬会把控制平衡点减半
- 直流电压 Vd=67.5kV（12 脉动）时 VDC_LCC（半桥对地）=33.75kV·cosα−压降（中点接地）

## 八、LCC 接入交流系统（黑盒并网）的条件（2026-08-22，IEEE39 接入前学习）

### 1. 交流系统强度（SCR，最关键）
- SCR = 换流母线短路容量 / 直流额定功率。强系统 SCR>5、弱系统 2~3、极弱 <2
- LCC 换相靠电网电压：弱系统电压波动大 → 触发角抖动、换相失败风险、谐波谐振
- IEEE39（新英格兰 39 节点）230kV 网 + 10 台发电机：母线短路容量数十 GVA，
  挂 60MW 级 LCC 时 SCR >> 10，完全满足

### 2. 换相电压质量
- 三相平衡（负序分量会直接进入直流侧，产生 2 倍频非特征纹波）
- 电压畸变受限（谐波干扰换相角测量/锁相）
- 电压跌落深度受限（连续换相失败判据：Vd 跌落超过 cosγ 裕度）

### 3. 无功需求与补偿
- LCC 吸收无功 Q ≈ P·tanφ，φ≈arccos(cosα − Rc·Id/Vd0)，典型 Q ≈ 0.5~0.6·P
- 必须并联无功补偿（电容器组/滤波器），否则母线电压明显跌落
- 强系统（IEEE39）挂小容量 LCC 时影响小，但严格仍需补偿

### 4. 谐波滤波器（12 脉动特征谐波）
- 交流侧注入 12k±1 次：11 次 ≈ 9%、13 次 ≈ 7.7% 基波电流（无滤波时）
- 需 11/13 次单调谐/双调谐滤波器（或 C 型高通）
- 无滤波器：母线电压 THD 升高 → 影响其他用户 + 自身换相

### 5. 换相变压器
- 高压侧电压匹配母线（IEEE39 Bus39 = 230kV）→ V1=230kV，V2=25kV
- 漏抗 Xl=0.1~0.2pu（决定换相压降与 μ）
- YY + YD 双绕组 30° 移相构成 12 脉动

### 6. 同步与触发（已验证）
- 触发同步基准 = 原边母线电压（CB 端口经 nodeloop 取节点号）
- TfPh 补偿变压器相移（YD 馈电桥 −30°）；KB=1 解锁

### 7. 直流侧
- 平波电抗 Ld + 负载 + 接地参考（CIGRE 直流负直接接地/1MΩ 中点）
- 直流滤波器（可选，抑制 12 脉动纹波）

### 8. 启动
- Tblock 阻断启动（0.04s）或 α 从 90° 软启动，避免直流冲击

### 黑盒封装方法（PSCAD 模块 = UserCmpDefn）
- `UserDefnWizard`：`w.port.electrical(x, y, 'AC', dim=3)` 定义三相电气接口
- 模块内部电气接口自动生成 **master:xnode**（与 CIGRE Rectifier、IEEE39 T1_39 同构）
- 内部电路与 xnode 同名电气连接；外部实例端口即三相电气端口
- 控制接口用 `w.port.input/output`（REAL/INTEGER/LOGICAL）——IORD 指令、VDC/IDC 观测
