# LCC 换流器 PSCAD 模型 — 验证记录

- 日期：2026-08-22
- 模型：`ess_lcc`（F:\ESS\ess_lcc.pscx，由 `demo29_lcc.py` 构建）
- 类型：12 脉动 LCC 整流器（单端）+ 定电流（CC）控制
- 软件：PSCAD 5.0.0（EMTDC v5.00 R#93051001）

## 一、模型拓扑

```
60kV/60Hz 交流源 (source3, Ctrl=0, Vm=Es=60kV)
  │ N3 (dim=3)
  ├─→ 换相变压器 T_YY (60/25kV, Xl=0.18pu)  N1→N2 → 6脉动桥 BRG1 (TfPh=0°)
  └─→ 换相变压器 T_YD (60/25kV, Xl=0.18pu)  N1→N2 → 6脉动桥 BRG2 (TfPh=−30°)
  原边星点 G1 接地；副边星点 G2 浮动
  桥 N 端口 = 副边三相功率；CB 端口 ← nodeloop(原边母线) X1 节点号；KB=1 运行

直流侧：
  BRG1.DP → Ld(0.2H) → 电流表(IDC) → Rl(60Ω) → BRG2.DN
  BRG1.DN ─ BRG2.DP（串联中点，经 1MΩ 接地作参考）
  VDC_LCC：BRG1.DP 对地（≈Vd/2）

控制（定电流 CC）：
  IDC(kA) → realpole 滤波(G=1.0, T=0.0012s) → sumjct(IND=IDF, INF=IORD)
  → pi_ctlr(GP=0.75, TI=0.0544s, YLO=0.0873, YHI=1.5708, YINIT=0.5236) → α(弧度)
  → 两桥 AO（同名 datalabel 扇出）；AM/GM 测量输出 → 显示
```

## 三、稳态验证结果（理论对照）

### 工况 1：IORD = 1.0 kA

| 量 | 测量（t>0.4s 均值） | 理论 | 偏差 |
|----|----|----|----|
| IDC | 1.012 kA | 1.00 kA（指令） | +1.2% |
| α | 14.5° | ~14°（由 Vd=Id·Rl 反推） | ✓ |
| VDC_LCC | 30.28 kV（半桥对地） | 33.75·cos14.5°−压降≈30.3 kV | ✓ |
| γ | 149.7° | 180−α−μ=180−14.5−15.8≈149.7° | ✓ |

理论校验：
- Vd0 = 2×1.35×25kV = 67.5 kV（12 脉动）
- 换相电抗 Xc = 0.18×25²/60 = 1.875 Ω；Rc = 3Xc/π = 1.79 Ω
- Vd = 67.5·cos14.5° − 1.79·1.012 ≈ 65.3−1.8 = 63.5 kV → Id = 63.5/60 ≈ 1.06（含源阻抗≈60.6 kV/60 Ω=1.01 ✓）

### 工况 2：IORD = 0.5 kA

| 量 | 测量 | 理论 | 偏差 |
|----|----|----|----|
| IDC | 0.510 kA | 0.50 kA（指令） | +2.0% |
| α | 61.8° | cosα=Vd/67.5，Vd≈30.6kV → α≈62° | ✓ |
| VDC_LCC | 15.13 kV | 30.6/2 | ✓ |

## 四、动态验证（定电流控制跟踪）

- 工况 1→2：IORD 1.0→0.5 kA 时 α 从 14.5° 升至 61.8°、Id 从 1.01 降至 0.51 kA
- 控制方向正确：Id > Iord → α 增大 → Vd 降低 → Id 回落（负反馈）
- PI 参数参考 CIGRE（GP=0.7506/TI=0.0544），限幅 5°~90°（弧度 0.0873~1.5708）
- 启动：Tblock=0.04s 阻断 → KB=1 解锁 → α 初值 30° → 收敛至稳态

## 五、关键技术结论（已对照 CIGRE benchmark 生成代码逐项验证）

1. **xfmr-3p2w（View=1）**：N1/N2（dim=3）是原/副边三相绕组端口；G1/G2（dim=1）是
   星点/中性端口（原边星点 G1 接地、副边 G2 浮动）
2. **g6p200_2（View=1）**：N 端口（dim=3）是交流功率；**CB 端口（Integer）是交流同步
   基准节点号**（经 nodeloop.X1 输出节点号接入）；**KB=1 解锁、KB=0 闭锁**；
   AO 在 FP=0 时为弧度、FP=3 时为度
3. **同步**：触发同步取原边母线电压（nodeloop），副边功率经 N 端口，相位差由
   TfPh 补偿（YD 馈电桥 −30°）
4. **source3**：Vm 与 Es 必须同时设置（Es 是实际输出，默认 230kV）
5. 电流滤波 realpole 增益必须为 1（kA 量纲直通），CIGRE 的 G=0.5 是 pu 标幺配合

## 七、直流电压纹波分析（2026-08-22 补充，用户询问"为何 Vd 振荡"）

### 实测（t>0.4s 稳态，IORD=1.0kA，α=14.5°）

| 通道 | 均值 | 峰峰值 | 基波频率 |
|------|------|--------|----------|
| VDC_LCC（半桥对地） | 30.29 kV | 10.8 kV（24.7~35.5） | 355.7 Hz |
| IDC | 1.012 kA | 9 A（0.9%） | — |
| α | 14.5° | ±0.57° | 15 Hz（缓慢收敛） |
| γ | 149.7° | ±0.01° | 5 Hz |

### 结论：12 脉动换流器固有换相纹波，非故障

1. **频率**：VDC_LCC 测的是单桥 6 脉动电压（BRG1.DP 对地，中点 1MΩ 接地），
   基波 355.7 Hz ≈ 360 Hz（6×60）；12 脉动总电压纹波主频为 720 Hz（12×60）。
   FFT 若见 360/720 Hz → 换相脉动；不是控制失稳（α/γ 纹波极小、收敛缓慢）
2. **幅值**：单桥 6 脉动纹波理论 ΔV_pp = √2·Vll·[cosα−cos(α+30°)] = 35.36×0.255 ≈ 9.0 kV
   （实测 10.8 kV，略高因无直流滤波电容）；12 脉动总电压纹波 = 2·Vd0·sinα·sin15°，
   **随 α 增大而增大**（α=5°≈3kV，α=62°≈31kV）
3. **电流纹波仅 0.9%**：平波电抗 Ld 工作正常，系统健康
4. **减小方法**：加大 Ld（CIGRE 0.5968H）、Rl 并联直流滤波电容（10~50µF，最有效）、
   加交流 11/13 次滤波器；**无需调 PI**（调 Kp/Ki 无法消除换相纹波）
