# ESS 储能模型 — PSCAD 控制操作说明

## 一、模型控制结构（三通道）

```
电网 60kV ──Rg/Lg──┬──Lf/Rf── 受控电流源 VSC (注入 id_ref/iq_ref)
                   └──Cf──┐
                     PCC   ├── [VP 电压表] → 控制器测量
                           ├── [IG 网侧电流表] → P/Q 测量 (网侧)
                           └── [IC 变流器电流表] → 电流测量
```

控制器 `ess_ctl`（画布中部，图符 "ESS CTL"）内部：
1. **测量通道**: PLL 锁相 (0.707/94.2) → Park 变换 → P/Q/V 测量 (低通 TPQ=0.02s 滤谐振)
2. **附加支持通道**: A01-A07 附加有功 (DP_DC/DP_REN/DP_LOAD 输入) + R01-R05 附加无功 (V_REF)
3. **外环通道**: P/Q 外环 (KPP=0.22, KIP=0.01) → id_ref/iq_ref → 限幅 1.1pu → 注入
4. **手动电流通道**: MAN_EN=1 时直接用 ID_M/IQ_M 作为电流参考

## 二、控制输入位置（画布左下角 11 个 const 组件）

| 信号 | 含义 | 范围建议 | 交付默认 |
|---|---|---|---|
| P_REF | 外环有功参考 | -1.0 ~ 1.0 pu (1pu=100MW) | 0.0 |
| Q_REF | 外环无功参考 | -1.0 ~ 1.0 pu (1pu=100Mvar) | 0.0 |
| VD_REF | V 模式 d 轴电压参考 | 0.9 ~ 1.1 pu | 1.0 |
| V_REF | 附加无功电压参考 | 0.9 ~ 1.1 pu | 1.0 |
| MODE_Q | 外环模式: 1=V 模式, 2=Q 模式 | 1 或 2 | 2 |
| DP_DC | 直流侧功率 (附加有功) | -1.0 ~ 1.0 pu | 0.0 |
| DP_REN | 新能源功率 (附加有功) | -1.0 ~ 1.0 pu | 0.0 |
| DP_LOAD | 负荷功率 (附加有功) | -1.0 ~ 1.0 pu | 0.0 |
| ID_M | 手动 d 轴电流参考 | -1.1 ~ 1.1 pu (1pu=1.36kA) | 0.5 |
| IQ_M | 手动 q 轴电流参考 | -1.1 ~ 1.1 pu | 0.2 |
| MAN_EN | 1=手动电流模式, 0=外环 P/Q 模式 | 0 或 1 | 0 |

## 三、GUI 操作步骤（PSCAD 中改控制）

### 方法 A: 修改 const 值（推荐，不动脚本）
1. 打开 `F:\ESS\ess_full.pscx`
2. 左下角找到要改的 const 组件（如 P_REF），**双击**它
3. 弹出属性框 → 修改 **Value** 参数（如 0.5）→ 确定
4. 工具栏 **Build**（构建）→ **Run**（运行）
5. 结果在右侧 Graph Frame 的多面板曲线中查看

### 方法 B: 修改脚本重建（批量/切换模式）
1. 编辑 `F:\ESS\demo28_ess_full.py`
2. 顶部 `MANUAL = 0` 改 `1` 即切换为手动电流模式初始状态
3. 或修改 `refs` 列表中的默认值
4. 命令行运行: `python F:\ESS\demo28_ess_full.py`（自动构建+运行+打印稳态值）

## 四、控制实验建议

### 实验 1: 外环有功跟踪 (P_REF)
- 初始: MAN_EN=0, P_REF=0 → P≈0, Q≈0, V≈60.1kV（已验证）
- 改 P_REF=0.5 → P 向 50MW 收敛（KIP=0.01 慢积分, 趋势正确）
- 改 P_REF=-0.3 → 反向注入（放电）

### 实验 2: 手动电流控制 (MAN_EN=1)
- 改 MAN_EN=1, ID_M=0.5, IQ_M=0.2 → id=0.68kA, iq=0.27kA 精确跟踪（已验证）
- ID_M 调 0.8 / IQ_M 调 -0.3 → 观察 ID_K/IQ_K 面板跟随

### 实验 3: 附加有功支持 (DP_*)
- DP_DC=0.2 → 附加有功通道输出 ~0.2pu 电流指令叠加到外环

### 实验 4: V/Q 模式切换 (MODE_Q)
- MODE_Q=2（Q 模式）: Q_REF 控制无功
- MODE_Q=1（V 模式）: VD_REF 控制 PCC 电压

## 五、观察面板（Graph Frame, 10+3 面板）
面板顺序: ID_K (d 轴电流), IDR_K (d 轴参考), IQ_K (q 轴电流), IQR_K (q 轴参考),
P_MW, Q_MVAR, V_KV (PCC 电压), IC_A/B/C (三相电流 RMS),
THETA (PLL 角), IC_A_raw / IG_A_raw (原始电流监视)

## 六、注意事项
- 启动瞬间 "Voltage chatter" 警告为电网源接入瞬态, 不影响结果
- 手动模式与外环模式通过 MAN_EN 切换; 外环模式下 ID_M/IQ_M 不生效
- 软启动 TSS=0.5s: 外环模式下前 0.5s 参考为 0（PLL 先锁定）
- 参数修改: ess_ctl 双击可改全部控制器参数（PLL/外环/内环/附加增益）
